# fcrypt - Format v0
This document outlines the unstable (pre-release) file format for fcrypt.

## Key Derivation
Each encrypted file uses a unique key, regardless of whether the password is the same. This key is generated using Argon2id (version 19), with an iteration count of 2, memory cost of 65536, and parallelism of 1. The keys are generated with a random 32-byte salt (the "salt") to ensure uniqueness. This key will be referred to as the "master key".

Next, we derive two 32-byte keys from the master key using the key derivation function of BLAKE3. 

The keys will be referred to as the "encryption key" and "mac key" respectively. 

The encryption key is generated with a context of `fcrypt v1.1 [encryption key]`, and the mac key is generated with a context of `fcrypt v1.1 [hmac key]`. 

Both context strings are ASCII-encoded.

## Format

Each encrypted file consists of 3 parts: 
- the original file's contents encrypted with AES-256-CTR, using the encryption key (the "ciphertext")
- the salt
- the authentication tag (BLAKE3 keyed hash of the ciphertext, using the mac key as key material, the "tag"). 

Therefore, the file structure is:
```
ciphertext || salt || tag
```
